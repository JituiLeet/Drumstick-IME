## 1.0.0 - Accessibility copy
- Added optional `DrumstickAccessibilityService` for user-initiated screen-text copy.
- First use prompts the user to enable Accessibility in Android Settings.
- Copy reads accessible text only when the user invokes Copy and excludes Drumstick's own package.
- Added an in-IME permission/explanation panel; no keyboard or navigation interception is performed by the accessibility service.
